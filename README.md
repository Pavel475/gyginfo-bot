# Telegram-бот «Игровой справочник»

Индивидуальный проект: Telegram-бот на Node.js для быстрого поиска информации о видеоиграх через **RAWG Video Games Database API** с переводом описания на русский язык, формированием краткой карточки и локальным хранением истории запросов и избранного.

## Возможности

- Поиск игр по названию и вывод структурированной карточки (название, год выхода, студия-разработчик, жанры, рейтинг, краткое описание на русском, ссылка на источник).
- Автоматический перевод описания на русский язык (с безопасным откатом к оригинальному тексту при недоступности сервиса перевода).
- Постоянная клавиатура с кнопками **«⭐ Избранное»** и **«🕘 История»**, а также inline-кнопки **«⭐ В избранное»** / **«✅ В избранном (убрать)»** и **«🔁 Повторить поиск»**.
- Поддержка команд `/start`, `/help`, `/favorites`, `/history`.
- Локальное хранение истории и избранного в JSON-файле (`data/storage.json`) без развёртывания внешних баз данных и серверов.

## Структура проекта

- `src/index.js` — точка входа и цикл Long Polling (`getUpdates`).
- `src/config.js` — загрузка переменных окружения из `.env` и валидация обязательных ключей.
- `src/services/gamesApi.js` — клиент RAWG API и нормализация данных об игре.
- `src/services/translator.js` — перевод описания на русский язык с откатом к исходному тексту.
- `src/formatters/gameCard.js` — форматирование карточки игры.
- `src/storage/store.js` — чтение и атомарная запись истории и избранного в `data/storage.json`.
- `src/handlers/botHandlers.js` — обработка команд, текстовых запросов, кнопок и ошибок.
- `.env.example` — пример файла конфигурации окружения.

## Требования и локальный запуск

1. Установите **Node.js** (проверено на версии `24.16.0`).
2. Склонируйте репозиторий и перейдите в его директорию:
   ```bash
   git clone https://github.com/Pavel475/gyginfo-bot.git
   cd <имя-репозитория>
   ```
3. Скопируйте .env.example в .env и заполните обязательные переменные (TELEGRAM_BOT_TOKEN и GAMES_API_KEY).
4. Запустите бота: npm start.

## Проверка работы

1. Откройте бота в Telegram и отправьте /start — появится приветственное сообщение и нижняя клавиатура с кнопками «⭐ Избранное» и «🕘 История».
2. Отправьте название игры (например, Skyrim или Portal 2) и убедитесь, что пришла карточка с данными и inline-кнопками.
3. Нажмите «⭐ В избранное», проверьте появление файла data/storage.json, а затем откройте избранное и историю через кнопки или команды /favorites и /history.
